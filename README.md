# 🍽️ Sahi Dastarkhwan – Responsive Food Delivery Website

A modern, responsive food delivery landing page built using **HTML5, CSS3, JavaScript, jQuery, AOS, and Ionicons**. This project focuses on creating an attractive user interface with smooth animations, responsive layouts, and a seamless browsing experience across all devices.
